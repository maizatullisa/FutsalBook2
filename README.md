# FutsalBook V2

**FutsalBook** adalah aplikasi web untuk booking lapangan futsal secara online.  
Versi ini merupakan pengembangan lanjutan yang dikerjakan secara individu oleh saya **Maizatul Lisa Aisyah** dengan peningkatan besar pada tampilan dan fitur.

---

## 🎯 Tentang Project Ini

Versi terbaru ini mencakup berbagai peningkatan signifikan, di antaranya:

- 🔄 **Redesign tampilan** diantaranya :
  1. halaman login-register : mengubah warna card login-register menjadi versi dark galaxy serta memberi sentuhan galaxy pada latar belakang card login-register
  2. halaman home & field booking : mengubah warna keseluruhan, redesign tampilan latar belakang, sedikit mengubah tampilan home
  3. halaman riwayat booking : redesign total design tampilan riwayat booking
  4. halaman profile : redesign total halaman profile user
  5. navbar : mengubah warna dan tampilan navbar
  6. landing-page : menambahkan halaman landing yang sebelumnya belum ada
  7. halaman rating : mengubah warna card dan tampilan latar belakang
- 🎨 **Implementasi menyeluruh halaman admin yang sebelumnya belum ada**
- 🛠️ **refaktor struktur backend**
